# Upgrade all dependencies to latest stable versions

## Why

The project is one Expo SDK behind (55 vs 56, released May 2026) and carries an unmaintained ESLint stack (ESLint 8 + `eslint-config-airbnb-typescript`, which pins @typescript-eslint 7 and will never support flat config). Upgrading now keeps the app on supported, security-patched versions and unblocks future tooling upgrades that all require ESLint flat config.

## What Changes

- **Expo SDK 55 → 56**: React Native 0.83.2 → 0.85.3, React 19.2.0 → 19.2.3, all `expo-*` packages to 56.x, native modules aligned to SDK 56 pins via `expo install --fix`. Hermes v1 becomes the default JS engine. Committed `android/`/`ios/` directories regenerated via prebuild.
- **Independent JS deps to latest stable**: i18next ^26 + react-i18next ^17 (paired major), @testing-library/react-native ^14, moti ^0.30, lint-staged ^17, concurrently ^10, plus assorted minors/patches.
- **BREAKING (dev tooling)**: ESLint 8 → 10 with migration from legacy `.eslintrc.js` to flat `eslint.config.js`; `eslint-config-airbnb-typescript` removed; @typescript-eslint 7 → 8; `eslint-config-expo` 55 → 56.
- **Removal**: deprecated `@testing-library/jest-native` dropped in favor of RNTL 14 built-in matchers.
- **Deliberate holds (latest stable policy, not npm-latest)**: typescript 5.9.3 (TS 6.0 is transitional, not validated by Expo 56), @types/jest 29 (jest-expo 56 still runs Jest 29), and SDK-56-pinned natives (react-native 0.85.3 not 0.86, gesture-handler ~2.31 not 3.x, reanimated 4.3.1, worklets 0.8.3, @shopify/flash-list 2.0.2).

## Capabilities

### New Capabilities

- `dependency-baseline`: the dependency set tracks latest stable versions compatible with the current Expo SDK; native module versions follow Expo SDK pins; documented holds for intentionally back-pinned packages.
- `lint-toolchain`: ESLint flat-config setup on ESLint 10 / typescript-eslint 8 preserving all existing custom rules (no-console, jsx-no-literals, restricted imports, import sorting) without the abandoned airbnb-typescript preset.

### Modified Capabilities

(none — no existing specs)

## Impact

- `package.json` / `bun.lock` — nearly every dependency line.
- `android/`, `ios/` — regenerated by `expo prebuild --clean` (large mechanical diff).
- `.eslintrc.js`, `.eslintignore` — deleted, replaced by `eslint.config.js`; `lint`/`lint:fix` scripts drop `--ext`.
- `jest.setup.ts` and test files — jest-native matcher imports removed; RNTL 14 adjustments.
- App code — only as driven by tsc/lint/test failures (expected hot spots: expo-router 56 types, i18next 26 types in `src/i18n/`).
- `docs/workspace-instructions/Tooling.md` (and CLAUDE.md if commands change) — updated to describe the flat-config lint setup.
